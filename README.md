# ✦ Dra. Ana Beatriz Mello — Landing Page de Psicologia Clínica

Uma landing page premium, moderna e responsiva desenvolvida para a psicóloga clínica **Dra. Ana Beatriz Mello**. O projeto foi planejado com foco na experiência do usuário (UX), transmitindo acolhimento, profissionalismo e facilitando o agendamento de consultas.

---

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias web fundamentais puras, garantindo alta performance, SEO otimizado e flexibilidade de customização:

*   **HTML5**: Estrutura semântica focada em acessibilidade e SEO.
*   **CSS3**: Estilização moderna e layout totalmente responsivo (Mobile-first e adaptado a desktops) utilizando variáveis CSS customizadas, animações fluidas e efeitos como Glassmorphic e Parallax.
*   **Vanilla JavaScript**: Lógica de interface dinâmica para animações de rolagem (Intersection Observer API), animação de contadores estatísticos, comportamento do menu hambúrguer e validação/simulação interativa do formulário de contato.

## 🎨 Características de Design e UX

1.  **Paleta de Cores Harmônica**: Uso de tons suaves e modernos baseados em HSL (como tons lilás/roxo e variações neutras) para inspirar tranquilidade e saúde mental.
2.  **Responsividade Premium**: Menus inteligentes e layouts que se adaptam perfeitamente de telas de smartphones a monitores 4K.
3.  **Micro-interações e Animações**:
    *   **Efeito Parallax**: Elementos flutuantes na seção Hero reagem suavemente ao movimento do mouse.
    *   **Intersection Observer**: Elementos de texto e cartões aparecem na tela suavemente à medida que o usuário faz a rolagem (`fade-in`, `fade-up`, `fade-left`).
    *   **Efeito de Shake**: Campos obrigatórios do formulário balançam visualmente caso o usuário tente enviar dados em branco ou inválidos.
    *   **Indicador Ativo Inteligente**: Os links do menu de navegação ganham destaque de forma dinâmica quando a respectiva seção é visualizada na tela.

## ⚙️ Como Executar Localmente

Como o projeto é construído em HTML/CSS/JS puro, ele não requer a instalação de pacotes ou processos de build complexos:

1.  Clone este repositório:
    ```bash
    git clone https://github.com/Eduardo11-est/2606-landpage-psicologia.git
    ```
2.  Navegue até o diretório do projeto:
    ```bash
    cd "02 Landing Page"
    ```
3.  Abra o arquivo `index.html` em qualquer navegador web de sua preferência ou utilize uma extensão de servidor local de desenvolvimento (como a *Live Server* do VS Code).
